### Метод Монте-Карло для вычисления π

Метод Монте-Карло основан на статистическом моделировании. Для вычисления π используется следующий подход:

**Геометрическая интерпретация:**
- Квадрат со стороной 2 (от -1 до 1) имеет площадь 4
- Вписанный круг единичного радиуса имеет площадь π
- Отношение площадей: π/4

**Алгоритм:**
1. Генерируем случайные точки в квадрате `[-1, 1] × [-1, 1]`
2. Проверяем попадание в круг: `x² + y² ≤ 1`
3. Вычисляем отношение точек внутри круга к общему количеству
4. Умножаем на 4 для получения π

```
π ≈ 4 × (точек внутри круга) / (всего точек)
```

### Параллельные вычисления в Python

| Метод | Библиотека | Описание | Особенности |
|-------|------------|----------|-------------|
| **Потоки** | `ThreadPoolExecutor` | Параллельное выполнение в одном процессе | Подходят для I/O задач |
| **Процессы** | `ProcessPoolExecutor` | Параллельное выполнение в разных процессах | Подходят для CPU-задач |
| **Последовательный** | `for` цикл | Выполнение на одном ядре | Простая реализация |

**Преимущества параллельных вычислений:**
- Ускорение вычислений за счет распараллеливания
- Эффективное использование многоядерных процессоров
- Обработка больших объемов данных
